# Original project context

This repository is a **clean-room portfolio reconstruction**, not a release of an employer system or its original source code.

The original proof of concept combined a ServiceNow REST integration, a Vellum conversational layer, scheduled reporting and triage jobs, and human-reviewed ticket actions. It was a working alpha system. The original source is not retained here.

This project recreates the operational ideas using invented records and a local-only interface:

- queue-risk identification rather than raw ticket-volume reporting;
- onboarding correlation to find missing account or hardware work;
- a dry-run stale-ticket policy;
- approval-gated action proposals with a visible audit outcome.

No employer names, production data, credentials, integration endpoints, screenshots, or original prompts are included.
